# @cmls/nimbus

Nimbus is the Cumulus desired-state manifest layer. This package exposes the
stable TypeScript contracts used by agents and tooling. The Rust compiler crate
is `cmls-nimbus`.

Source of truth: https://github.com/Cumulus-s/cumulus-create
Public mirror: https://github.com/Cumulus-s/nimbus

Nimbus tooling is AGPL-3.0-only.
