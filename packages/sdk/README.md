# @cls/sdk

Apache-2.0 composed SDK for Cumulus apps and agents. It re-exports the public
Auth and DB package surfaces and provides a small system client for account
console flows.

Source of truth: https://github.com/Cumulus-s/cumulus-create
Public mirror: https://github.com/Cumulus-s/sdk

Nimbus is shipped separately as `@cls/nimbus` and `cls-nimbus` because
the compiler/provider tooling is AGPL-3.0-only.
